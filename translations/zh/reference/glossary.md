# 术语表

```{glossary}
Nix
    构建系统与包管理器。

    读作 /nɪks/（"Niks"）。

    :::{seealso}
    - [Nix 参考手册](./nix-manual.md)
    - [Nix 源代码](https://github.com/NixOS/nix)
    :::

Nix language
    用于为 {term}`Nix` 声明软件包与配置的编程语言。

    :::{seealso}
    - [](reading-nix-language)
    - [Nix 语言参考](https://nix.dev/manual/nix/stable/language)
    :::

Nix expression
    用 {term}`Nix language` 编写的表达式。

Nix file
    包含 {term}`Nix expression` 的文件（`.nix`）。

Nixpkgs
    用 {term}`Nix` 构建的软件发行版。

    读作 /nɪks ˈpækɪʤɪz/（"Nix packages"）。

    :::{seealso}
    - [Nixpkgs 参考手册](https://nixos.org/manual/nixpkgs)
    - [Nixpkgs 源代码](https://github.com/NixOS/nixpkgs)
    :::

NixOS
    基于 {term}`Nix` 与 {term}`Nixpkgs` 的 Linux 发行版。

    读作 /nɪks oʊ ɛs/（"Niks Oh Es"）。

    :::{seealso}
    - [NixOS 参考手册](https://nixos.org/manual/nixos)
    - [NixOS 源代码](https://github.com/NixOS/nixpkgs/tree/master/nixos)
    :::
```
